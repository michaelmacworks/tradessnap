**Document 4: Tech Stack & Logic Flow**  
  
This document outlines how we move from a contractor’s sweaty thumb hitting "Record" on a job site to a fully formatted SEO case study on your website.** 1. The High-Level Workflow** To make this "set it and forget it" for the contractor, the flow needs to be frictionless: 1. **Input:** Contractor uses a mobile app (like Zapier Central, GoHighLevel, or a custom interface) to upload **Photos** and a **Voice Note**. 2. **Processing:** * **Whisper (OpenAI):** Transcribes the rough audio into text. ◦ **Claude (Anthropic):** Takes the transcript + Image Descriptions and "cleans" them into the three deliverables using the rules we've established. 3. **Output:** Data is pushed via API to the Website (WordPress/Webflow), Google Business Profile, and Social Media (Buffer/Hootsuite).** 2. Logic & Prompt Engineering Structure** When you send data to Claude, the "System Prompt" should follow this logic: • **Variable Injection:** {{Business_Name}}, {{Location}}, {{Transcript}}, {{Image_Context}}. • **The "Jargon Lookup" Step:** Claude should first identify any technical specs (e.g., "R-38 Insulation") and look up the homeowner benefit (e.g., "Keeping the heat in and the bills down"). • **The "Geo-Tagging" Step:** Claude must ensure the {{Location}} appears in the H1, the first paragraph, and the hashtags.** 4. Handling "Messy" Data** The system must be built to handle "Garbage In." If a contractor says, *"Yeah, we're in Dublin, fixed a leaky pipe, it was a mess, all good now,"* the Tech Stack needs to: 1. Recognize "Dublin" as the location. 2. Infer the "Problem" (Water damage/stress). 3. Infer the "Solution" (Professional plumbing repair).
